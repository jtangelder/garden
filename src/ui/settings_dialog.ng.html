Hoe stel je gratis Google OAuth in (2 minuten)
  1. Open de Google Cloud API Library en schakel de Google Drive API, Google Sheets API en Google Calendar API in (allemaal gratis).
  2. Ga naar APIs & Services → Credentials → Create Credentials → OAuth client ID (Applicatietype: Web application).
  3. Voeg https://jorik.dev en http://localhost:4200 toe onder Authorized JavaScript origins.
  4. Plak de gegenereerde Client-ID hierboven en maak optioneel een gratis sleutel aan bij Google AI Studio.
